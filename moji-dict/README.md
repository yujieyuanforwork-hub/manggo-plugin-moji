# MOJi辞書 Manggo 插件

基于 [MOJi辞書](https://www.mojidict.com/) 公开接口的 Manggo 原生插件，**无需任何配置**即可直接使用。移植自 Pot-App 的
[pot-app-translate-plugin-moji_dict](https://github.com/TechDecryptor/pot-app-translate-plugin-moji_dict)，并按 Manggo 的结构化词典结果重写。

## 提供的服务

| 服务 | 类型 | 说明 |
| --- | --- | --- |
| MOJi辞書 | `translation` / `resultType: dictionary` | 日语词典查询，返回读音、声调、罗马音、分词性义项、配套例句、文法条目和相关词条。 |
| MOJi辞書 发音 | `speech` | 朗读 MOJi 收录词条的原生录音（真人录音，不是 TTS 合成）。 |
| 在 MOJi辞書 中查询 | `action` | 划词后用系统默认浏览器打开 MOJi 网页版搜索结果。 |

词典服务需要在「服务设置 - 翻译」中添加，发音服务需要在「服务设置 - 语音」中添加；划词动作在插件安装后自动出现在「划词助手」的动作列表中。

## 结果内容

以查询 `勉強` 为例：

```text
勉強            标签: N1 / N5 / 考研
かな:  べんきょう ◎    (含发音音频)
ローマ字: benkyou
1. [名·自他·三类] 用功学习，用功读书；学习知识，积累经验。
     例: 一夜漬けの勉強。 —— 临阵磨枪。
     例: 化学を勉強する。 —— 学习化学。
2. [名·自他·三类] 勤奋,热心（工作）。
     例: こんな夜遅くまでお仕事とはずいぶん勉強ですね。 —— 这么晚了还在工作,真热心啊！
3. [名·自他·三类] 廉价,贱卖。（値引き。）
4. [例文]
     例: 日本語の勉強、お疲れ様です。 —— 学日语辛苦啦。
属性: 来源 / 词条链接 / 相关词条 ×4
```

- 查询文法（如 `ながら`）时，除词条义项外还会追加 `[文法]` 义项。
- 查询整句时若没有匹配的词条，会返回 MOJi 的例句检索结果；完全没有命中时抛出可读错误。

## 发音服务的适用范围

MOJi 只为**词典收录的词条和文法条目**提供录音，没有任意文本的语音合成接口，因此发音服务：

- 支持按词形（`勉強`）或假名读音（`べんきょう`）朗读，两者都会命中同一个词条。
- 默认只朗读精确匹配的词条；`勉強した` 这类活用形或整句会提示未收录。关闭「仅朗读精确匹配的词条」后会退回朗读搜索到的第一个词条（`勉強した` → `勉強`）。
- 返回 `{ bytes, format: "mp3" }`，音频直接取自 MOJi 的录音文件。

如果需要朗读任意句子，请在「服务设置 - 语音」中再配置一个通用 TTS 服务，把本服务留给日语单词查询。

## 配置项

词典服务（全部可选，默认值开箱可用）：

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 查询词条详情 | 开 | 额外请求词条详情以获得读音、词性、分义项和配套例句；关闭后只用搜索摘要，少一次网络请求。 |
| 获取发音音频 | 开 | 请求 MOJi 的词条发音地址，可在结果中直接朗读。 |
| 包含文法条目 | 开 | 把文法搜索结果作为独立义项展示（最多 5 条）。 |
| 包含例句搜索结果 | 开 | 把例句搜索结果作为「例文」义项展示。 |
| 每个义项的例句数量 | 3 | 取值 0–20。 |
| 相关词条数量 | 4 | 其余搜索结果作为「相关词条」属性展示，取值 0–20。 |

发音服务：

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 仅朗读精确匹配的词条 | 开 | 词形或读音不完全一致时直接报错；关闭后朗读搜索到的第一个词条。 |
| 最大朗读长度 | 32 | 超过该长度的文本直接报错，避免对整句发起无意义的查询，取值 1–200。 |

划词动作：

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| 最大选区长度 | 32 | 选区超过该长度时不显示动作。 |
| 仅日语选区显示 | 关 | 开启后只在选区包含假名或汉字时显示动作。 |

## 语言映射

MOJi 是日中词典，插件只声明实际支持的语言：`auto`、`ja_JP`、`zh_CN`、`zh_TW`。查询词与目标语言无关，释义始终为中文（部分词条含日文原文注释）。

## 使用的接口

均为 MOJi 网页版使用的公开接口，`POST https://api.mojidict.com/parse/functions/<function>`：

| 接口 | 用途 |
| --- | --- |
| `union-api` → `search-all` | 搜索词条（102）、文法（106）、例句（103）。 |
| `fetchWord_v2` | 取词条详情：读音、声调、罗马音、标签、词性、分义项、例句。 |
| `fetchTts_v2` | 取词条发音音频地址（仅 `tarType: 102`，例句没有录音）。 |

请求体携带 MOJi Web 客户端的公开参数，用户无需提供账号或密钥。返回 429 或 5xx 时会自动重试一次。接口由 MOJi 提供，可能随其网页版更新而变化。

## 打包与安装

```bash
./package.sh
```

生成 `dist/com.manggo.community.moji-dict.mplugin`，在 Manggo 的「插件管理」页面安装即可。Windows Git Bash 没有 `zip` 时脚本会自动改用 Python 打包。

## 开发说明

- 入口脚本导出 `translate`（词典）、`tts`（发音）、`canOpenInMoji`（划词预检）、`openInMoji`（划词执行）。
- 词典结果严格遵循 Manggo 的 `{ kind: "dictionary", dictionary: {...} }` 结构，详见仓库根目录 [README.md](../README.md)。
- 详情与发音请求失败时会静默降级为搜索摘要，不影响主流程；搜索请求失败会抛出可读错误。
- 修改内容后请同步更新 `manggo.plugin.json` 中的 `version` 并重新打包验证。
